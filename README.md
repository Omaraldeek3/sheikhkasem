# شركة الشيخ قاسم — الفرونت اند

فرونت اند جديد لموقع **شركة الشيخ قاسم لصناعة المواد الغذائية والتوابل — القدس**.
كل النصوص والصور والشعارات مأخوذة من الموقع القديم
[sheikhkasem.com](https://www.sheikhkasem.com/en/) — لا محتوى مُختلق.

## التشغيل

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

## التقنية

- **Next.js 15** — App Router، كل الصفحات مبنية مسبقاً (static / SSG)
- **Tailwind CSS 4** — التوكنز معرّفة في `app/globals.css` داخل `@theme`
- **TypeScript** — `npx tsc --noEmit` نظيف
- عربي بالكامل، اتجاه RTL (`<html lang="ar" dir="rtl">`)

## الهوية البصرية

**أحمر الشركة `#EA1C2D`** مأخوذ من الشعار نفسه. ولأن النص الأبيض فوقه يعطي تبايناً
4.5:1 بالحدّ، تُستخدم ثلاث درجات:

| التوكن | القيمة | الاستخدام |
|---|---|---|
| `brand` | `#EA1C2D` | الشعار، المساحات، الخطوط |
| `brand-deep` | `#C8101F` | خلفيات الأزرار — النص الأبيض 5.9:1 |
| `brand-lite` | `#FF7A82` | النص والروابط على الأرضية الداكنة — 7:1 |

**الأرضية** سمّاق مطحون `#2A1214` — أسود دافئ يميل للأحمر، لا رمادي محايد ولا كريمي.
**الحروف** Reem Kufi للعناوين (كوفي، أقدم أنماط الخط العربي)، IBM Plex Sans Arabic
للنصوص، Amiri (نسخ) لنص الإرث وحده.

**العنصر المميز — طيف الأصناف.** كتالوج الشركة سبعة أصناف، ولكل صنف لون مأخوذ من لون
المادة نفسها. الشريط في الافتتاحية هو الكتالوج مرسوماً كطيف، ويعمل كتنقل، ويتلوّن رأس
كل صفحة صنف بلونه. الشعارات الفرعية للشركة تصادق هذا المنطق: زعتر القدس أخضر، الفواكه
المجففة برتقالية، البقوليات زرقاء.

| الصنف | اللون | المصدر |
|---|---|---|
| بهارات وتوابل | `#E0A32A` | كركم |
| بقوليات وحبوب | `#7E8B4A` | عدس أخضر |
| منتجات بلدية | `#46613F` | زعتر بلدي |
| مكونات الحلويات | `#D8C79A` | محلب |
| زيوت ومنكهات | `#7A2233` | دبس رمان |
| لوزيات وبذور | `#96703F` | قشرة لوز |
| فواكه مجففة | `#C4562B` | مشمش مجفف |

لون النص فوق كل لون (`ink`) مختار ليحقق تبايناً لا يقل عن AA.

## الصور

الصور نُزّلت من الموقع القديم (كانت على `framerusercontent.com`) وصُغّرت وحُوّلت إلى
webp عبر `scripts/prepare-images.mjs`. الأصول الأصلية كانت حتى 8000×4000 و4MB للصورة؛
الحجم الآن **1.0MB** لكل صور المنتجات و**264KB** للشعارات.

```bash
node scripts/prepare-images.mjs
```

- `public/logo-lockup.webp` — الشعار الأفقي. يُعرض على رقعة بيضاء (`.logo-chip`) لأنه
  أحمر مصمّم للأبيض، كما يظهر على العبوة
- `public/products/*.webp` — صور المنتجات، معظمها مصوّر في مطبخ أبيض واحد فتتناسق
- `public/brands/*.webp` — شعارات العلامات التجارية السبع
- `public/products/mill.webp` — صورة المطحنة، تُستخدم في قسم الإرث

الأصول الأصلية في `.scratch/img` (خارج git). لإعادة تنزيلها، الروابط في
`.scratch/img/urls.txt`.

## التوافق مع الهواتف

- **صفر تجاوز أفقي** على 320 / 375 / 414 / 768 / 1280
- **مساحات اللمس** ≥ 44px للأزرار والتنقل، و≥ 24px لكل رابط (حد WCAG 2.5.8 AA)
- طيف الأصناف يتحول إلى **سلّم عمودي** تحت 1024px، حيث لا يتّسع سبعة أقسام أفقياً
- الأعمدة المزدوجة التي تحوي بطاقة أو صورة تبقى عموداً واحداً حتى 1024px
- التذييل: عمود واحد على الجوال، عمودان على التابلت، أربعة على الشاشات الكبيرة
- `sizes` محدّد لكل صورة فلا يُنزّل الجوال نسخة سطح المكتب

## ما ينتظر محتوى من الشركة

هذه المواضع موسومة بـ `TODO` في `lib/content.ts` وتظهر في الموقع بمكوّن
`ContentPending` (ليست صفحات مكسورة — فيها دعوة للتواصل):

1. **نص «نظرة عامة»** — `/about-us/general`. صفحة الموقع القديم لم تكن قابلة للقراءة.
2. **نص «سياسة الشركة»** — `/about-us/policy`. نفس السبب.
3. **قوائم نقاط البيع لكل مدينة** — `/salespoints/[city]`. المدن التسع موجودة، أما
   أسماء المتاجر وعناوينها فغير متوفرة.
4. **العدّادات الثلاثة** (منتجات معبئة، منتجات مصنعة، طاقم العمل) — كانت تظهر في الموقع
   القديم بقيمة `+0`، فتُركت في `counters` بانتظار أرقام صحيحة. الرئيسية تعرض حالياً
   `facts` وهي أرقام حقيقية فقط: 1934، +90 صنفاً، 7 أصناف، 9 مدن.
5. **صورة منتج لصنف الفواكه المجففة** — غير موجودة في الموقع القديم، فتُعرض علامته
   التجارية بدلاً منها.
6. **قائمة المنتجات الكاملة** — الأسماء الموجودة حالياً (`products` في كل صنف) مقروءة
   من العبوات الظاهرة في صور الموقع، وليست قائمة الشركة الرسمية. القائمة الكاملة في
   الكتالوج الخارجي.

## نموذج التواصل

`components/ContactForm.tsx` فرونت اند فقط: يفتح برنامج البريد لدى الزائر برسالة معدّة
مسبقاً إلى `contact@sheikhkasem.com`، فيعمل بدون سيرفر. لربطه بباك اند، استبدل جسم
`handleSubmit` بطلب `POST` إلى نقطة النهاية.
